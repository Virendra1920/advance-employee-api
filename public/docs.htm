REST API Documentation

Complete guide to integrate and consume the Enterprise Employee API.

POST /api/admin/login
Admin Authentication
Generates a JWT token required for protected routes.
Request Body (JSON)
{ "email": "virendra@admin.com", "password": "adminpassword" }
GET /api/employees
Fetch All Employees
Retrieves a complete list of employee records.
Success Response
{ "success": true, "count": 50, "data": [ { "_id": "64f1...", "name": "Kundan", "department": "IT" } ] }
POST /api/add-employee 🔒 Requires JWT
Create New Record
Adds a new employee to the database. Strictly validated using Zod.
Request Body
{ "name": "Rahul Sharma", "email": "rahul@example.com", "phone": "9876543210", "age": 30, "department": "HR" }
